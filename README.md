# java-mouse-jiggler

Имитатор бурной деятельности - перемещает курсор мыши в случайном направлении (вверх, вниз, влево или вправо) на заданное
количество пикселей через заданный интервал, возвращает курсор в исходное положение (если нужно).

Используются только компоненты стандартной библиотеки Java

## Возможности

- Интервал перемещения, интервал возврата и смещение задаются в окне
  (в миллисекундах и пикселях, диапазон `1..999999`).
- Случайное перемещение и возврат курсора включаются и отключаются независимо.
- Возврат не выполняется, если пользователь сдвинул курсор после автоматического перемещения
- Изменённые настройки применяются без перезапуска.

## Требования

- JDK 21 или новее для сборки.
- JRE 21 или новее для запуска.

## Сборка

Сборка выполняется только средствами стандартной библиотеки Java
(`javac` и `jar`).

Windows:

```bat
build.bat
```

Linux:

```bash
bash build.sh
```

В результате в папке `dist` появляются три файла:

- `MouseJiggler.jar` — программа;
- `run.bat` — запуск в Windows;
- `run.sh` — запуск в Linux.

## Запуск

Windows:

```bat
dist\run.bat
```

Linux:

```bash
dist/run.sh
```

Либо напрямую:

```
java -jar dist/MouseJiggler.jar
```

## Структура проекта

```
src\java\mousejiggler\
├── MouseJigglerApp.java    — пользовательский интерфейс (Swing)
├── JiggleEngine.java       — алгоритм перемещения и возврата курсора
├── CursorController.java   — управление курсором (java.awt.Robot)
└── Settings.java           — настройки и нормализация ввода
```
